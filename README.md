# Eco-Thrift Store Template 🌿

A lightweight, responsive, and conversion-optimized web template designed specifically for sustainable fashion brands, preloved clothing stores, and thrift businesses.

## Why This Project Exists?
In the world of sustainable fashion, **brand storytelling** and a clear **customer journey** are essential. Many small business owners in the preloved fashion industry struggle to build an online presence from scratch. This open-source template aims to solve that by providing a ready-to-use, aesthetically pleasing foundation built purely with HTML, CSS, and Vanilla JavaScript.

## Features
- 🎨 **Minimalist Earth-Tone Design:** Tailored for eco-friendly aesthetics.
- 📖 **Storytelling Focus:** Dedicated sections to highlight brand mission and the "loop" of circular fashion.
- 🛍️ **Curated Grid Layout:** Clean product displays to showcase unique preloved items.
- 📱 **Fully Responsive:** Looks great on desktop and mobile.
- ⚡ **Lightweight & Fast:** No heavy frameworks, purely vanilla code.

## How to Use
1. **Fork or Download** this repository.
2. Open `index.html` in any browser to preview the site.
3. Customize the content:
   - Change the placeholder texts in `index.html` to match your brand.
   - Replace the Unsplash image URLs in `style.css` (`.placeholder-img-1`, etc.) with images of your own products.
   - Update the `--primary-color` in `style.css` if you want a different brand accent color.
4. **Deploy:** This static site can be hosted for free on **GitHub Pages**, Vercel, or Netlify in just a few clicks!
